# Security policy

If you find a security vulnerability in HuntLoop, please report it privately
through GitHub's private vulnerability reporting instead of opening a public
issue: https://github.com/Niramay-Kelkar/HuntLoop/security/advisories/new

This project uses CodeQL, GitHub secret scanning, and Dependabot to help
catch known vulnerabilities and exposed secrets. Reporting privately gives
time to fix an issue before it is disclosed publicly.
